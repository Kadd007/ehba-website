# EHBA Website

## Elly's Hair And Beauty Academy + Salon

EHBA is a digital platform combining:

- Professional hair and beauty services
- Online salon booking
- Beauty education and courses
- Student learning management
- Business management tools

---

## Technology

Built with:

- Next.js
- TypeScript
- Tailwind CSS
